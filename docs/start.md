# 第一次刷机

## 准备电脑和词典笔

1. 在机身或包装确认完整型号 **YDP031CHNSTD、16 GB**，在原厂设置确认 **OS 3.4.6**。首次安装器还会读取实际分区和原厂启动文件。已安装双系统的笔请保留当前安装。
2. 用 Apple Silicon Mac 或 Ubuntu 电脑，准备一根能传数据的 USB 线。下载、虚拟机、约 15.5 GB 的整笔备份和制作临时文件都需要空间，建议开始前在个人文件夹所在磁盘留出 **50 GiB**。备份会一直保存在本机。
3. Mac 准备好 Homebrew、Apple 命令行工具和 Python 3.9 或更高版本。Ubuntu 需要 Python 3.9+、curl 和可使用 sudo 的账户。安装器会准备其余工具。Mac 可用「终端」分别运行 `brew --version`、`xcode-select -p`、`python3 --version` 检查。[Homebrew](https://brew.sh/) · [Python](https://www.python.org/downloads/macos/)
4. 确认原厂系统已允许自己的电脑使用 USB 调试，且电脑只连着这一支笔。需要先在原厂界面完成设备支持的授权。维护模式也可由设备所有者事先进入。

## 下载和打开

从[发布页](https://github.com/who-andy/ydp031-cherry-android/releases/tag/v0.2.0-rc.1)的 **Assets** 下载 **Cherry-YDP031-Installer.zip**。解压，打开里面的 **Cherry-YDP031** 文件夹。

- **Mac** 双击 **Start.command**。如果系统拦截这个未签名的社区脚本，可以先看脚本内容，或在终端输入 `bash `，把 Start.command 从 Finder 拖进终端，再按回车。
- **Ubuntu** 在解压后的文件夹打开终端，输入 `bash Start.command`。
- 想先确认文件完好，可运行 `bash Start.command --self-test`。看到「安装包自检通过」即可。这个动作无需联网或连接词典笔。

## 选择「1 安装双系统」

1. **下载**。安装器从上游取得 Android 基础文件、Mali 图形库和 Via 浏览器，校验后放在个人文件夹的 `CherryPen` 中。首次使用 Mac 时还会下载 Ubuntu 制作环境。网络较慢时可以先选「2 只准备下载」，完成后重新打开再选 1。
2. **连接和备份**。笔进入维护模式后屏幕可能暂时变黑。程序先识别设备，再读取整笔，随后从设备再读一次核对。此时保持连接。自己这支笔的备份位置会显示在窗口中。
3. **自动制作**。安装器读取备份中的词库、原厂词典界面和发音资源，做好双系统的安装文件。普通用户无需编译内核或手工拼镜像。
4. **确认写入**。核对窗口中的序列号，输入这个号码并按回车。程序完成写入和回读后会发出重启指令。等实际看到安卓桌面，再进行下面的检查。若中断，保留 `CherryPen` 文件夹，重新打开同版安装器。
5. **试扫和切换**。打开「设备模式」选「学习模式」，回到桌面直接扫一个英文单词，点喇叭听发音。再扫相邻两行，第一行抬笔后一秒内开始第二行。要回原厂，点「系统切换」；原厂桌面的绿色「返回安卓」可切回来。

## 恢复到安装之前

恢复会覆盖安装以来新增的用户数据，先另存需要的文件。保留 `~/CherryPen/private/这支笔的序列号/stock.img` 和同目录的 `stock.img.sha256`。将同一支笔连到电脑，打开安装器选「3 恢复自己的原厂备份」，核对序列号后确认。备份里的个人资料请自行保管。
