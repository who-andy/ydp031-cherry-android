**有道词典笔 3 双系统安装器**保留原厂系统，并在安卓学习模式下还原原生扫词流程。落笔可唤起横屏词典，查看释义、发音和整句翻译；约一秒内接扫下一行可合并翻译。

在本页下方展开 **Assets（附件）**，按电脑系统下载：

| 电脑 | 安装包 | 解压后打开 |
| --- | --- | --- |
| Windows 11 x64 | [Cherry-YDP031-Windows.zip](https://github.com/who-andy/ydp031-cherry-android/releases/download/v0.2.0-downloads.1/Cherry-YDP031-Windows.zip) | `Start-Windows.exe`。[Windows 刷机与恢复教程](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-downloads.1/docs/windows.md) |
| Apple Silicon Mac 或 Ubuntu | [Cherry-YDP031-Installer.zip](https://github.com/who-andy/ydp031-cherry-android/releases/download/v0.2.0-downloads.1/Cherry-YDP031-Installer.zip) | Mac 双击 `Start.command`，Ubuntu 运行 `bash Start.command`。[首次授权、刷机与恢复教程](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-downloads.1/docs/start.md) |

适用机型为 **YDP031CHNSTD、16 GB、原厂 B 槽 OS 3.4.6**。首次安装会联网下载基础文件，从自己的词典笔读取原厂资源并保存整笔备份。

两个附件沿用已发布的测试版，校验值见 **SHA256SUMS**。开发笔已实测扫词、接句、发音与原厂往返切换。Windows 直连实机的完整刷入和恢复，以及第二支全新原厂笔的首次冷启动仍待验证。[实机效果和验证范围](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-downloads.1/docs/results.md) · [自行构建](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-downloads.1/docs/build.md)
