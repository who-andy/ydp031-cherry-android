# 这支词典笔怎样运行 Android

## 启动与存储

开发机运行 ARM64 Android 8.1（API 27），从适配过的 Linux 4.4.194 内核启动。内核继续驱动笔尖、触摸屏、显示、扬声器等硬件。安卓框架通过板级驱动和硬件抽象层使用这些设备。APK 在安卓系统中运行，无需在词典主界面内启动模拟器。

RC1 首次安装方案与早期开发机的分区迁移方案有一处重要区别。RC1 保留两个原厂 system 分区，将安卓数据放入 userdisk 下的 data-desktop.ext4。不要照搬早期开发记录中的分区偏移或迁移步骤。

| 存放位置 | 安装后的用途 |
| --- | --- |
| boot A | 此笔专用的 Android 启动镜像 |
| boot B、system B | 原厂 3.4.6 的启动与系统 |
| system A | 保留原厂内容 |
| userdisk | 原有词库、发音资源及数据，另加安卓运行文件、2.5 GiB 数据文件和原厂桌面按钮 |
| A/B 启动记录 | 两个系统的选择与试启动次数 |

## 从笔尖到词典

学习模式监听笔尖触点。落笔时开始连续采集，滑过的一行由原厂引擎拼接和识别。安卓宿主把结果显示在横屏词典页面，单词可以查看释义和发音，连续两行可以合并翻译。相机应用使用同一个扫描头获取预览和录像。游戏模式暂停词典和 OCR 进程，因此能释放内存。

## 安装器如何处理每一支笔

1. [disk.py](../disk.py) 检查主副 GPT、板级布局、原厂启动镜像和四份设备标识。备份保存在电脑上。
2. [prepare.py](../prepare.py) 只读挂载源分区，按内容摘要导入原厂资源，在新副本中生成用户分区文件。[boot.py](../boot.py) 用目标笔的序列号生成启动镜像，[factory_button.py](../factory_button.py) 将「返回安卓」加入副本中的原厂桌面。
3. [install.py](../install.py) 仅读写安装计划覆盖的范围。先核对目标与备份，再写入差异块并回读，最后更新启动选择。独立恢复使用原始备份与备份时记录的摘要。

要验证这些行为，可以先跑[磁盘副本演练](recovery.md)，再核对[本版验收记录](validation.json)。
