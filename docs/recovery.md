# 中断和恢复

| 看到的情况 | 怎样处理 |
| --- | --- |
| 下载或平台文件校验失败 | 重新打开同一发行包，先选 2。完整且校验正确的下载会复用。上游文件如已换版，请在发布页查找新版并报告文件名。 |
| 找不到 USB 设备 | 检查数据线、原厂系统对当前电脑的调试授权，拔掉其他安卓设备后再试。 |
| 型号、分区、原厂 B 或词典资源校验失败 | 记录完整型号、原厂版本和错误文字。该布局或资源版本需要单独适配。 |
| 制作镜像时空间不足 | 保管好 `CherryPen/private` 中的原厂备份。在当前电脑腾出空间后再运行同版安装器。 |
| 写入期间 USB 断开 | 让同一支笔重新进入 Loader，保留原备份和 update-rc2 目录，重新选 1。安装器会先检查现有扇区内容。 |
| 要恢复原厂状态 | 先保存后来新增的内容，选 3 并确认序列号。恢复需要最初的 stock.img 和 stock.img.sha256。 |
