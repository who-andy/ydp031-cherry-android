Windows 11 x64 用户请下载 **Cherry-YDP031-Windows.zip**，选择「全部解压」，双击 **Start-Windows.exe**。选 4 可先检查包，选 1 安装，选 3 恢复。支持有道词典笔 3 **YDP031CHNSTD、16 GB、原厂 B 槽 OS 3.4.6**。

双系统保留原厂词典，并在 Android 下支持落笔唤起、整行识别、连续扫两行合并翻译及发音。安装器共用 Android 和驱动，在自己电脑上从词典笔备份导入原厂资源，自动生成对应安装文件。

首次使用请准备 Ubuntu-24.04（WSL 2）、usbipd-win 和 Windows ADB，并在存放 Ubuntu 的磁盘预留 50 GiB。[Windows 刷机与恢复教程](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-rc.2-win.1/docs/windows.md) · [开发机实机效果](https://github.com/who-andy/ydp031-cherry-android/blob/v0.2.0-rc.2-win.1/docs/results.md)
