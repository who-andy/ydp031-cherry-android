# 安装器在背后做什么

刷机前，用户在词典笔上授权 USB 调试；制作镜像时，电脑上的 Linux 环境使用管理员权限挂载磁盘副本；真正写入词典笔的是 Rockchip 维护模式（Loader）。**首次安装无需预先取得原厂系统的 root。** 如果你正准备刷机，请按电脑系统选择 [Windows 教程](windows.md)或 [Mac / Ubuntu 教程](start.md)。

## 一次安装会用到哪些权限

| 看到的提示 | 谁授予权限 | 用来做什么 |
| --- | --- | --- |
| 词典笔上的 USB 调试或授权提示 | 用户按原厂设备提供的方式开启调试并允许自己的电脑连接 | ADB 识别词典笔，向原厂系统请求重启到 Loader。固件还要允许这次重启。 |
| Ubuntu 终端的 `sudo` | Linux 按当前账户的 sudo 配置决定是否放行或提示密码 | 安装依赖、访问维护模式的 USB 设备、挂载和制作 ext4 镜像。电脑端的命令由 sudo 启动。 |
| Windows 的管理员确认框 | Windows 用户确认 UAC 提示 | 首次共享匹配的 Loader 设备时，启动器通过 `runas` 执行 `usbipd bind`，随后把该 USB 设备接到 WSL 2。WSL 内的 sudo 使用 Ubuntu 账户。 |
| 安装后安卓应用请求 root | 用户在新安卓系统中通过 Magisk 管理应用授权 | 只关系到安卓内申请特权的应用，与首次刷机时的 USB 授权分别管理。 |

在 Apple Silicon Mac 上，ADB 和 Rockchip USB 工具由 Mac 宿主机运行。安装器在 Lima 的 Ubuntu 虚拟机里调用 sudo 安装依赖、挂载镜像；USB 仍由 Mac 读写。直接用 Ubuntu 时，这些环节都在本机执行。已按设备支持的方式进入 Loader 的词典笔，可以从设备识别环节开始。[电脑工具](tools.md) · [Windows USB 转接实现](../build/windows/StartWindows.cs)

## 从连接到写入

1. **准备文件。** 安装器校验下载包内的组件，并从上游取得与本版匹配的 Android 基础文件、Mali 图形库和 Via 浏览器。选择「只准备下载」可以在接笔前完成这一步。[下载与校验代码](../fetch_inputs.py)
2. **识别同一支笔。** 从原厂桌面开始时，向导要求 ADB 只列出一支状态为 `device` 的笔。进入 Loader 后重新核对设备标识和分区布局，并将读到的序列号与刚才的 ADB 序列号比较。[向导](../wizard.py) · [设备识别](../disk.py)
3. **留下恢复用的备份。** 安装器读取整个 eMMC 用户区，生成 `stock.img`，再读一次设备，与电脑上的备份一起核对 SHA-256。成功后保存 `stock.img.sha256`。这两个文件位于对应序列号的私人备份目录。[备份实现](../install.py)
4. **在电脑上生成安装文件。** 程序只读挂载备份里的原厂分区，按清单校验并导入词库、词典界面、OCR 和发音等所需资源。在用户分区的工作副本中加入安卓文件及「返回安卓」按钮，最后比较新旧内容，生成有差异的区块。[制作流程](../prepare.py) · [原厂资源清单](../factory-files.json)
5. **确认后才写入。** 用户输入目标序列号后，安装器核对备份、当前设备、差异块和允许写入的范围。实际修改的是用户分区中的双系统文件、boot A 和启动选择记录。发生写入的块会回读核验，启动选择最后更新，随后设备重启。[写入和恢复实现](../install.py) · [分区用途](how-it-works.md)

### 为什么同款笔也要生成自己的安装文件

同型号共用一套 Android、内核和板级驱动。差异来自笔里已有的内容：启动模板要填入本机序列号，词典资源从本机备份导入，安装器还要保留这支笔现有的用户数据。即使两支笔系统版本一样，需要替换的区块也可能不同。用户点击安装后，这些工作都会自动完成。[启动模板](../boot.py) · [通用镜像重建](../image_parts.py)

## 恢复

在同一支笔上选择「恢复」，安装器核对备份摘要和目标序列号，再用备份恢复安装器涉及的用户分区、boot A 和启动记录。安装后新增的数据会随恢复而回退。具体操作、备份位置和中断后的处理见[故障排查与恢复](recovery.md)。

开发者可运行 `python3 wizard.py --help` 查看向导参数，或运行 `python3 install.py --help` 查看 `identify`、`backup`、`prepare`、`install` 和 `restore` 等独立入口。
